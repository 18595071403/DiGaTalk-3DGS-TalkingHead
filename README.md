# DiGaTalk-3DGS-TalkingHead

Official repository for the paper "DiGaTalk: Heterogeneous Motion Parameterization for Audio-Driven 3D Gaussian Talking Heads".

We propose a region‑adaptive hybrid motion modeling framework for audio‑driven 3D Gaussian talking heads, which adopts heterogeneous driving branches for face and mouth regions to balance facial motion smoothness and lip fine‑grained details.
Code, pretrained models, and documentation will be released in a future update.
